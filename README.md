# Universal Agent Starter (Manufacturing, Trading & Business)


Two demo agents you can run locally:
1. **RFQ → Quote Agent**: Upload an RFQ CSV, get price suggestions and a draft quote.
2. **AP 3‑Way Match Agent**: Upload PO/GRN/Invoice CSVs, get mismatches & an exceptions report.


No API keys needed. Node.js 18+ required.


## Quickstart
1) Install Node 18+: https://nodejs.org
2) In a terminal:
```bash
npm install
npm start
